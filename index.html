About

Building reliable infrastructure, end to end

I'm a Senior IT System Administrator with over a decade of experience across Microsoft technologies, network security, cloud infrastructure, and virtualization. Most recently I spent over a year at Microsoft as a Microsoft 365 Identity Support Engineer, working deep in Entra ID and hybrid identity for enterprise customers — and I've since returned to system administration, now applying that background to build a secure Linux environment for AI infrastructure.

Where I Add Value

  • ✓ Keep Windows Server and Active Directory environments secure, patched, and highly available
  • ✓ Manage Azure backup and recovery through Recovery Services vaults and Azure Monitor alerting
  • ✓ Support identity and access management with Microsoft Entra ID, conditional access, and hybrid identity
  • ✓ Configure and maintain FortiGate firewalls and network security controls
  • ✓ Automate recurring administration tasks with PowerShell
  • ✓ Build and run on-prem Linux infrastructure for AI workloads

How I Create Impact

I focus on infrastructure that stays reliable under pressure — backups that actually restore, alerts that fire before a small issue becomes an outage, and identity systems that stay secure without slowing people down. I'm currently expanding that focus into DevOps, Linux, and AI-adjacent workflows, moving from keeping systems alive toward designing the infrastructure that runs them.
